# Security Policy

Ту-95 Bear is a static, client-side game. It has no server, no accounts and no network requests apart from loading Google Fonts. It stores only game progress in your browser's `localStorage`.

## Reporting a vulnerability

If you find a security issue, such as a way to run injected script through the page, please **don't open a public issue**. Instead:

- Use GitHub's [private vulnerability reporting](https://github.com/harrisbasra/tu95-bear/security/advisories/new), or
- Email **harrisbasra@gmail.com**.

You can expect an acknowledgement within a few days. Only the latest version on `main` is supported.
